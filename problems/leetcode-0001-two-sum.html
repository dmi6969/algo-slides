找出兩個數，讓它們的和等於 target

  • 給一個長度為 $n$ 的整數陣列 nums 和一個整數 target
  • 找出兩個不同的索引 $i \ne j$，使 $\text{nums}[i] + \text{nums}[j] = \text{target}$
  • 題目保證只有一組答案，回傳順序不限
  • 輸入：nums、target
  • 輸出：索引 $[i, j]$

限制

  • $2 \le n \le 10^4$
  • $-10^9 \le \text{nums}[i],\ \text{target} \le 10^9$
暴力解最多約 $\frac{n(n-1)}{2} \approx 5 \times 10^7$ 次比較，通常還能通過；但題目的 Follow-up 要求比 $O(n^2)$ 更快的方法。
n 最大 10⁴，兩兩配對大約是 n² / 2 = 5 × 10⁷ 組，在 LeetCode 上通常還能通過。 不過題目最後的 Follow-up 問能不能做到比 O(n²) 更快，這份簡報的重點就是那個 O(n) 的做法。

範例（Example 2）

INPUT

nums = [3,2,4], target = 6

OUTPUT

[1,2]

其他範例：nums = [2,7,11,15], target = 9 → [0,1]； nums = [3,3], target = 6 → [0,1]

選 Example 2 當主要範例，是因為答案不在陣列最前面，比較看得出搜尋的過程。 Example 3 的兩個數相同，之後會用它說明為什麼不會把同一個元素用兩次。

逐步說明：檢查每一組 $(i, j)$

INPUTnums = [3,2,4], target = 6 OUTPUT[1,2]
步驟$(i, j)$$\text{nums}[i] + \text{nums}[j]$說明
1$(0, 1)$$3 + 2 = 5$$5 \ne 6$，繼續
2$(0, 2)$$3 + 4 = 7$$7 \ne 6$，繼續
3$(1, 2)$$2 + 4 = 6$等於 target，回傳 $[1, 2]$

把所有組合都試一次就能找到答案，這就是暴力解的想法。

解題想法

暴力解

  • 兩層迴圈檢查每一組 $(i, j)$
  • 共 $\frac{n(n-1)}{2}$ 組，時間 $O(n^2)$

最佳解：hash map

  • 由左往右掃一次，記錄看過的數
  • 每個數只查一次，時間 $O(n)$
關鍵觀察：選定 $\text{nums}[i]$ 後，另一個數一定是 $$\text{need} = \text{target} - \text{nums}[i]$$ 問題從「找一組數」變成「查 need 有沒有出現過」，hash map 查詢平均只要 $O(1)$。
暴力解慢在對每個 nums[i]，都要往後一個一個找另一半。 但另一半的值其實是確定的：target − nums[i]。只要能快速知道這個值有沒有出現過、出現在哪個索引，就不用再掃一遍。 hash map 正好能做到：用數值當 key、索引當 value，查詢平均 O(1)。

用 hash map 走一次 Example 2

INPUTnums = [3,2,4], target = 6 OUTPUT[1,2]
$i$$\text{nums}[i]$$\text{need}$查詢前的 map（數值 → 索引）動作
03$6 - 3 = 3$$\{\}$沒找到，記錄 $3 \to 0$
12$6 - 2 = 4$$\{3 \to 0\}$沒找到，記錄 $2 \to 1$
24$6 - 4 = 2$$\{3 \to 0,\ 2 \to 1\}$找到 $2$ 在索引 $1$，回傳 $[1, 2]$
先查再存：查詢時 map 只包含索引 $j \lt i$ 的數，所以 $i = 0$ 的 $3$ 不會和自己配對；而 Example 3 的第二個 $3$ 能找到第一個 $3$。

程式碼（C++）

按 → 會依序高亮：第 4 行建立 map；第 5–6 行取出 nums[i] 並算出 need； 第 7–10 行查 map，找到就回傳；第 11 行把目前的數存進 map。 need 的範圍是 −2 × 10⁹ 到 2 × 10⁹，仍在 int 範圍內，不會溢位。

複雜度

項目複雜度原因
時間$O(n)$每個元素處理一次，hash map 的查詢與插入平均 $O(1)$
空間$O(n)$最壞情況下，map 要存 $n - 1$ 個數
$$T(n) = \underbrace{n}_{\text{iterations}} \times \underbrace{O(1)}_{\text{lookup + insert}} = O(n)$$

對照暴力解：時間 $O(n^2)$、空間 $O(1)$。這個解法是用 $O(n)$ 的額外空間換取時間。
