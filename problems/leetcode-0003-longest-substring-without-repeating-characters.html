找出沒有重複字元的最長子字串

  • 給一個字串 s，可能包含英文字母、數字、符號和空白
  • 子字串 $s[l..r]$ 必須連續，而且每個字元只能出現一次
  • 求這種子字串的最大長度 $r - l + 1$
  • 輸入：字串 s
  • 輸出：最大長度（空字串時為 $0$）

限制

  • $0 \le |s| \le 10^5$
枚舉所有子字串再逐一檢查是 $O(n^3)$，$n = 10^5$ 時一定超時，需要 $O(n)$ 的做法。
注意「子字串」和「子序列」的差別：子字串必須連續，子序列可以跳著選。 這題要的是子字串。

範例（Example 3）

INPUT

s = "pwwkew"

OUTPUT

3

其他範例："abcabcbb" → 3；"bbbbb" → 1

選 Example 3 當主要範例，是因為它有連續重複的 ww，而且可以用來說明子字串和子序列的差別。

逐步說明：從每個起點往右延伸

INPUTs = "pwwkew" OUTPUT3
起點 $l$往右延伸到出現重複為止長度
0pw（下一個 w 重複）$2$
1w（下一個 w 重複）$1$
2wke（下一個 w 重複）$3$
3kew（到字串結尾）$3$
4ew（到字串結尾）$2$
5w（到字串結尾）$1$
結果wke 或 kew$3$
注意：子字串必須連續。"pwke" 是子序列（subsequence），不是子字串，所以答案不是 $4$。

解題想法

暴力解

  • 枚舉所有子字串 $s[l..r]$，逐一檢查有沒有重複
  • 共 $O(n^2)$ 個子字串，每個檢查 $O(n)$，總共 $O(n^3)$

最佳解：sliding window

  • 維護一個沒有重複字元的視窗 $[l, r]$
  • 右端每次前進一格；遇到重複，左端直接跳過去
  • $l$ 和 $r$ 都只往右移，共 $O(n)$
關鍵觀察：記錄每個字元上一次出現的位置 $\text{last}[c]$。如果 $s[r]$ 已經在視窗裡出現過，左端直接跳到它的下一格： $$l \leftarrow \max\bigl(l,\ \text{last}[s[r]] + 1\bigr)$$ 左端只會往右移，不必回頭重新檢查。
暴力解浪費的地方在於：每換一個起點，就要從頭重新檢查。 其實視窗 s[l..r−1] 已經確定沒有重複，加入 s[r] 時，只要知道 s[r] 上次出現在哪裡，就能直接決定左端要移到哪。 用一個大小 256 的陣列記錄每個字元上次出現的位置，查詢只要 O(1)。

為什麼要取 max：以 "abba" 為例，讀到最後的 a 時，它上次出現在位置 $0$，已經在視窗左邊。如果直接設 $l = 0 + 1 = 1$，左端會往回跳，視窗 "bba" 就有重複了。

程式碼（C++）

按 → 會依序高亮：第 4–5 行準備 last 陣列（初始為 −1）和視窗左端；第 6–7 行右端逐格前進； 第 8 行就是 l ← max(l, last[s[r]] + 1)；第 9 行更新這個字元最後出現的位置；第 10 行更新答案。 字元先轉成 unsigned char，避免出現負的陣列索引。

複雜度

項目複雜度原因
時間$O(n)$右端走過每個位置一次，每步只做 $O(1)$ 的更新
空間$O(|\Sigma|)$last 陣列的大小固定是 $|\Sigma| = 256$，和 $n$ 無關
$$T(n) = \underbrace{n}_{\text{right moves}} \times \underbrace{O(1)}_{\text{update}} = O(n)$$

對照暴力解：時間 $O(n^3)$。
