找出總和最大的連續子陣列

  • 給一個長度為 $n$ 的整數陣列 nums，元素可能是負數
  • 子陣列 $\text{nums}[l..r]$ 必須連續且不可為空，其中 $0 \le l \le r \lt n$
  • 求所有子陣列中最大的總和 $\sum_{k=l}^{r} \text{nums}[k]$
  • 輸入：整數陣列 nums
  • 輸出：最大總和（一個整數）

限制

  • $1 \le n \le 10^5$
  • $-10^4 \le \text{nums}[i] \le 10^4$
子陣列共有 $\frac{n(n+1)}{2} \approx 5 \times 10^9$ 個，全部枚舉一定超時，需要 $O(n)$ 或 $O(n \log n)$ 的做法。
答案的絕對值最多是 10⁵ × 10⁴ = 10⁹，用 int 存得下，不會溢位。 子陣列必須「連續」而且「不可為空」，所以就算全部都是負數，答案也是最大的那個負數，不是 0。

範例（Example 1）

INPUT

nums = [-2,1,-3,4,-1,2,1,-5,4]

OUTPUT

6

其他範例：nums = [1] → 1； nums = [5,4,-1,7,8] → 23

這組範例有正有負，最能看出「什麼時候該捨棄前面的部分、重新開始」。

逐步說明：答案是 $[4, -1, 2, 1]$

往左延伸的任何一段（例如 $[1, -3]$）總和都是負的，往右的 $[-5]$、$[-5, 4]$ 也是，加進來只會讓總和變小，所以這一段不能再延伸。

解題想法

暴力解

  • 枚舉所有起點 $l$，往右延伸並累加
  • 共 $\frac{n(n+1)}{2}$ 個子陣列，時間 $O(n^2)$

最佳解：DP（Kadane's algorithm）

  • 只記錄以 $i$ 結尾的最大和 $dp[i]$
  • 由左往右掃一次，時間 $O(n)$
關鍵觀察：以 $i$ 結尾的最佳子陣列，要嘛接在以 $i-1$ 結尾的最佳子陣列後面，要嘛從 $\text{nums}[i]$ 重新開始： $$dp[i] = \max\bigl(dp[i-1] + \text{nums}[i],\ \text{nums}[i]\bigr)$$ 答案是 $\max\limits_{0 \le i \lt n} dp[i]$，初始值 $dp[0] = \text{nums}[0]$。
換個角度看這條式子：如果 dp[i−1] 是負的，接在它後面只會讓總和變小，不如從 nums[i] 重新開始。 所以 Kadane's algorithm 的直覺就是「前面的累計和一旦變成負的，就丟掉重來」。

程式碼（C++）

按 → 會依序高亮：第 4–5 行設定初始值 dp[0] 和 best；第 7–8 行就是遞迴式 dp[i] = max(dp[i−1] + nums[i], nums[i])； 第 9 行更新答案；第 11 行回傳。 因為計算 dp[i] 只需要 dp[i−1]，所以不用開整個 dp 陣列，一個變數 cur 就夠了。

複雜度

項目複雜度原因
時間$O(n)$每個位置只算一次 $dp[i]$，每次 $O(1)$
空間$O(1)$只用 cur 和 best 兩個變數，不必存整個 dp 陣列
$$T(n) = \underbrace{n}_{\text{positions}} \times \underbrace{O(1)}_{\text{one max}} = O(n)$$

對照暴力解：時間 $O(n^2)$。Follow-up 提到的分治法是 $O(n \log n)$，思路不同，但比 DP 慢。
