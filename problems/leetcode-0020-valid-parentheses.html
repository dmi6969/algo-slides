判斷括號字串是否正確配對

  • 字串 s 只包含 6 種字元：( ) [ ] { }
  • 每個右括號都要和同種類的左括號配對
  • 配對順序要正確：比較晚打開的括號要先關上
  • 輸入：括號字串 s
  • 輸出：合法回傳 true，否則回傳 false

限制

  • $1 \le |s| \le 10^4$
$n \le 10^4$ 時，$O(n^2)$ 約需 $10^8$ 次操作，有超時風險；最好找 $O(n)$ 的做法。
這題的重點不只是左右括號數量相同，還要種類相同、順序正確。 例如 "([)]" 數量完全對得上，但順序交錯，所以不合法。

範例（Example 5）

INPUT

s = "([)]"

OUTPUT

false

其他範例："()" → true；"()[]{}" → true； "(]" → false；"([])" → true

選 Example 5 當主要範例，是因為它的括號數量和種類都對得上，只有順序交錯，最能看出「順序」這個條件。

逐步說明：為什麼不合法

INPUTs = "([)]" OUTPUTfalse
步驟讀到的字元還沒關上的括號（舊 → 新）說明
1((打開一個小括號
2[( [再打開一個中括號
3)( [最近打開的是 [，卻用 ) 關閉，回傳 false

括號數量對了還不夠：右括號只能關閉「最近一個還沒關上」的左括號。

解題想法

暴力解

  • 反覆刪掉相鄰的 ()、[]、{}，直到刪不動
  • 最後剩下空字串就合法
  • 最多 $\frac{n}{2}$ 輪、每輪 $O(n)$，共 $O(n^2)$

最佳解：stack

  • 左括號推入 stack
  • 右括號和 stack 頂端比對，配對成功就彈出
  • 每個字元只進出一次，共 $O(n)$
關鍵觀察：右括號只能和「最近一個還沒關上的左括號」配對，也就是後進先出（LIFO），正好是 stack 的行為。
暴力解每一輪都要重新掃整個字串，找相鄰的一對括號刪掉，最壞情況要刪 n/2 輪。 但仔細看會發現，每次遇到右括號，要比對的永遠是「最近打開、還沒關上」的那個左括號。 這種「最後放進去的最先拿出來」的需求，正是 stack 的用途。

用 stack 走一次 Example 4

INPUTs = "([])" OUTPUTtrue
步驟字元動作stack（底 → 頂）
1(左括號，推入(
2[左括號，推入( [
3]頂端是 [，配對成功，彈出(
4)頂端是 (，配對成功，彈出（空）
結果掃完且 stack 為空回傳 true
回傳 false 的三種情況：遇到右括號時 stack 是空的、頂端的左括號種類不同、掃完後 stack 還有剩。

程式碼（C++）

按 → 會依序高亮：第 4 行建立 stack；第 6–9 行遇到左括號就推入； 第 10–12 行取出頂端，stack 是空的就直接不合法；第 13–16 行檢查種類是否相符； 第 18 行確認所有左括號都已經關上。

複雜度

項目複雜度原因
時間$O(n)$每個字元最多推入、彈出各一次，每次 $O(1)$
空間$O(n)$最壞情況全是左括號，stack 要存 $n$ 個字元
$$T(n) = \underbrace{n}_{\text{chars}} \times \underbrace{O(1)}_{\text{push / pop}} = O(n)$$

對照暴力解：時間 $O(n^2)$。
