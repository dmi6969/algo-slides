找出最長的嚴格遞增子序列有多長

  • 給一個長度為 $n$ 的整數陣列 nums
  • 子序列：刪掉 0 個或多個元素，剩下的元素保持原本的順序，不必連續
  • 要嚴格遞增：$\text{nums}[i_1] \lt \text{nums}[i_2] \lt \cdots \lt \text{nums}[i_k]$，其中 $i_1 \lt i_2 \lt \cdots \lt i_k$
  • 輸入：整數陣列 nums
  • 輸出：最長的長度 $k$

限制

  • $1 \le n \le 2500$
  • $-10^4 \le \text{nums}[i] \le 10^4$
$n \le 2500$ 時，$O(n^2) \approx 6.25 \times 10^6$ 的 DP 就能通過；但題目的 Follow-up 要求 $O(n \log n)$。
「子序列」和「子字串」不一樣：子序列可以跳著選，只要順序不變。 「嚴格遞增」代表相等的數不能放在一起，所以 [7,7,7] 的答案是 1。

範例（Example 1）

INPUT

nums = [10,9,2,5,3,7,101,18]

OUTPUT

4

其他範例：nums = [0,1,0,3,2,3] → 4； nums = [7,7,7,7,7,7,7] → 1

選 Example 1 當主要範例，是因為它的數字忽大忽小，最能看出每個位置能接在誰後面。

解題想法

暴力解

  • 枚舉所有 $2^n$ 個子序列，檢查是否遞增
  • 時間 $O(2^n \cdot n)$，$n = 2500$ 完全不可行

DP

  • $a[i]$：以 $\text{nums}[i]$ 結尾的最長遞增子序列長度
  • 往前找所有 $\text{nums}[j] \lt \text{nums}[i]$ 的 $j$，接在它後面
  • 答案是所有 $a[i]$ 的最大值，時間 $O(n^2)$
關鍵觀察：要把 $\text{nums}[i]$ 接在一個子序列後面，只需要知道那個子序列的最後一個數，所以用「以哪個數結尾」當作狀態： $$a[i] = 1 + \max\{\, a[j] \mid j \lt i,\ \text{nums}[j] \lt \text{nums}[i] \,\}$$ 沒有符合條件的 $j$ 時，$a[i] = 1$。
暴力解要檢查每一個子序列，數量是 2 的 n 次方。 但接上一個新的數時，我們只需要知道前面那個子序列的最後一個數，所以只要記錄「以每個位置結尾的最長長度」就夠了。 每個位置往前看一次所有比它小的數，總共 O(n²)。
