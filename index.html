Algo Slides

LeetCode 與 Codeforces 的演算法題解簡報。每一份簡報都用同樣的五個段落介紹一道題目：

  1. Problem overview
  2. Sample I/O
  3. Idea
  4. Coding
  5. Complexity

    這些簡報是怎麼做出來的

    每一份簡報都是 AI 讀取專案裡的 CLAUDE.md 之後，照同一套規則產生的。任何人都可以用相同的方式新增題目：

    1. 下載專案

      git clone https://github.com/dmi6969/algo-slides.git

    2. 開啟 Claude Code

      在專案資料夾執行 claude，它會自動讀取 CLAUDE.md 裡的規則。

    3. 輸入題目網址

      例如 新增這題：https://leetcode.com/problems/two-sum/。AI 會讀題、驗證程式碼、建立簡報，首頁也會自動出現新題目。Codeforces 題目要另外貼上題目內容。

    閱讀 CLAUDE.md ↗

    簡報操作：方向鍵翻頁，F 全螢幕，S 講者備註，Esc 投影片總覽。
